# 票据台账

本机可用的企业报销管理系统。账号、报销记录和附件会保存到当前目录的 `data/` 与 `uploads/` 中。

## 启动

在此目录执行：

```powershell
npm start
```

也可以直接双击 `start.bat`，它会启动服务并自动打开浏览器。

然后在浏览器打开 `http://localhost:3000`。

登录与注册页面均需选择账号身份。管理员和普通人员均只需填写姓名和密码。同一姓名可分别注册管理员和普通人员账号，登录时选择对应身份。首次注册时请选择管理员；后续注册账号请选择普通人员。管理员登录后可查看全员报销与附件，并将申请标记为已报销。普通人员只能查看自己的记录和附件。

普通人员登录后可在“我的资料”修改姓名和密码；保存后，管理员查看该员工资料时会读取最新信息。

## 数据与安全

- 密码使用 bcrypt 哈希保存，无法从数据库还原。
- 系统不收集或保存银行卡号及开户银行信息。
- 附件不提供公开网址，必须登录且具备对应权限才可打开。
- 请定期备份 `data/` 与 `uploads/` 两个目录，并限制服务器电脑的文件访问权限。

本项目默认供本机或受信任内网使用。如需开放到公网，请在部署前配置 HTTPS、反向代理、访问控制和定期备份策略。
